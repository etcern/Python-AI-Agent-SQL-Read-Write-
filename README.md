# Python-SQL-AI-Agent
This project contains a WireFrame for an/many AI agent/s using a mix of Python, HTML/CSS/JS and the Frameworks [langchain, langchain-ollama, pydantic, rich, fastapi, uvicorn[standard]].
---
# Note:
This Project has been completed using the help of ClaudeAI, especially on the Website Interface. <br><br>
This is just the base for an standard local AI prompting interface, that is working together with ollama API, in order to be able to Use local Chatbots inside a Web interface made out of python, open source and fully modular. The design of the website has been inspired by <a href="https://claude.ai/"> ClaudeAI </a> website. 
---
