Architecture How It's Built

Click any block to see what it does. Everything runs on your machine.

👤 You (Browser) Type questions in plain English
You open http://localhost:8501 in any browser. That's your chat window. You type a question like you'd ask a colleague. No SQL knowledge needed.
▼
📄 Streamlit app.py - The chat interface
Streamlit is a Python library that creates web pages from Python code. It draws the chat bubbles, sidebar, and input box. Think of it as the "screen" of the application. File: app.py
▼
🧠 Agent + LangChain agent.py - The brain that plans
The agent is a loop. It sends your question to the AI, checks if the AI wants to use a tool, runs that tool, sends the result back, and repeats until the AI has a final answer. LangChain is the framework that makes connecting AI to tools easy. File: agent.py
▼ ▼
🤖 Ollama + Qwen Local AI on your GPU
Ollama is the program that runs AI models on your computer. Qwen 2.5 Coder 14B is the specific AI model - it has 14 billion learned parameters and lives in your GPU's 16 GB VRAM. It reads text and generates responses, including deciding which tools to call. Configured in: config.py
🔧 Tools tools.py - 4 database functions
Tools are Python functions the AI can call. They are the AI's "hands." Without them it can only talk. With them, it can actually query the database. We have 4: list_tables, describe_table, sample_table, execute_sql. File: tools.py
▼
🗃 SQLite Database data/ecommerce.db - 108 KB
A SQLite database is just a file on your disk - no server needed. Ours contains 4 tables: products (97 rows), customers (100), orders (500), order_items (~1400). It simulates an e-commerce store. Generated by: setup_db.py

The 4 Tools What the AI Can Do

Without tools, the AI can only talk. With tools, it can act. These are its abilities.

📋

list_tables

Shows all tables in the database. The AI calls this first to understand what data exists.

Result: "customers, orders, order_items, products"
🔎

describe_table

Shows column names & types for a table. Lets the AI know what fields exist before writing SQL.

Result: "id (INTEGER) first_name (TEXT) email (TEXT)..."
📑

sample_table

Shows a few example rows. Sometimes the AI needs to see actual data to understand formats and values.

Result: (1, 'James', 'Smith', 'james@...')
⚡

execute_sql

Runs any SQL query. The most powerful tool. The AI writes SQL based on what it learned from the other tools.

SELECT COUNT(*) FROM customers WHERE country='US';

💡 Every tool has a "reasoning" parameter

Before calling any tool, the AI must explain why it's calling it. This forces it to think before acting and gives you a debug trail. For example: "I need to understand the orders table structure to write a proper JOIN query."

The Flow Step by Step

What happens from the moment you type a question to when you see the answer.

1. You type a question

"Who is my best customer?"

st.chat_input("Ask a question about your data...")

2. Streamlit sends it to the Agent

app.py calls the ask() function with your question and the chat history.

response = ask(query=prompt, history=history, model=model)

3. Agent sends everything to the AI

The system prompt + tools list + chat history + your question all get sent to Ollama.

response = model.invoke(history) # history includes EVERYTHING

4. AI model runs on GPU

Qwen 2.5 Coder processes all the text using your RX 9060 XT's 16 GB VRAM. It decides: "I should call list_tables first."

5. Tool executes

Agent sees the AI wants list_tables, runs it, gets back "customers, orders, order_items, products".

tool_response = call_tool(tool_call) # runs the Python function history.append(tool_response) # adds result to history

6. Loop repeats (AI thinks again)

The tool result goes back to the AI. It decides to call more tools (describe_table, execute_sql) or give a final answer. Steps 3-6 repeat until done.

7. Agent returns the final answer

When the AI responds with text and no tool call, the loop stops. That text is the answer.

if not tool_calls: # no more tools to call? return response.content # done! return the answer

8. You see the answer

Streamlit renders the markdown response in a chat bubble: "Your best customer is Nicole Bond with 12 orders totaling $1,847.50"

Keyword Bridges For Your Boss

Every new word connected to something familiar. Hover the blue wordsThese are keywords with built-in explanations! anywhere on this page for instant definitions.

LLM (Large Language Model)

🎯 You already know: Autocomplete on your phone
An LLM is autocomplete on steroids. Instead of predicting the next word, it predicts entire paragraphs. It learned patterns from billions of pages of text. Qwen 2.5 Coder is the LLM we use.

Ollama

🎯 You already know: VLC plays videos locally
Ollama is like VLC but for AI models. Instead of streaming from Netflix (cloud AI), you download the model and run it on your own machine. Private, free, no internet needed.

Agent

🎯 You already know: A new employee given instructions
An AI agent is like a new hire who reads the manual (system prompt), has access to specific tools (database queries), and figures out the steps to answer your question on their own. You don't tell it HOW, you tell it WHAT you need.

Tool Calling

🎯 You already know: Asking your assistant to look something up
You say "check my calendar." Your assistant knows to open the calendar app and look. Tool calling is the same: the AI says "I need to run a database query" and the system runs it for them.

System Prompt

🎯 You already know: A job description
The system prompt is the AI's job description. It says "you are a SQL analyst, respond in markdown, your audience is business analysts." Change the job description, change the AI's behavior entirely.

Context Window

🎯 You already know: A desk with limited space
The AI can only "see" a limited amount of text at once (8,192 tokens ~ 6,000 words). Like a desk: the more papers you pile on, the older ones fall off. That's why very long conversations eventually lose early context.

Temperature

🎯 You already know: "Strictly by the book" vs "get creative"
Temperature 0 = always gives the same answer (best for SQL, facts). Temperature 1 = creative, varied answers (good for brainstorming). We use 0 because we want accurate queries, not poetry.

Parameters (14B)

🎯 You already know: Brain cells
14 billion parameters = 14 billion tiny numbers that store everything the AI learned. More parameters = smarter but needs more memory. Our model (9 GB on disk) fits in your GPU's 16 GB VRAM.

VRAM

🎯 You already know: RAM, but for your graphics card
Your RX 9060 XT has 16 GB VRAM. The AI model must fit in VRAM to run on the GPU. Our 14B model takes ~9 GB, leaving 7 GB headroom. Bigger model = needs more VRAM.

LangChain

🎯 You already know: An adapter/converter plug for electronics
LangChain is a Python framework that plugs AI models into tools, databases, and APIs using a standard interface. It's the adapter between the AI brain and the database hands.

Tokens

🎯 You already know: Syllables in a word
AI doesn't read letters or words - it reads "tokens." Roughly, 1 token = 3/4 of a word. "Hello world" = 2 tokens. "Unbelievable" = 3 tokens. Context window of 8192 tokens ~ 6000 words.

RAG

🎯 You already know: Open-book exam vs closed-book
RAG = Retrieval Augmented Generation. Instead of asking the AI from memory (closed-book), you give it relevant documents to read first (open-book). It searches your files, then answers using what it found.

Scaling & Training Where To Go Next

From "just tweak a sentence" to "train your own model" - ordered by effort.

1

Change the System Prompt

Edit one text block in agent.py. Change the AI's personality, language, output format, or target audience. Takes 2 minutes.

5 minutes
2

Add Few-Shot Examples

Put example Q&A pairs in the prompt so the AI learns your preferred style. "When asked about revenue, always break it down by month."

15 minutes
3

Swap the AI Model

Change one line in config.py. Try bigger models for better SQL, smaller for faster responses. ollama pull llama3.1:8b

10 minutes
4

Connect Your Own Database

Point DB_PATH to any SQLite file. For PostgreSQL/MySQL, swap the cursor helper in tools.py. The AI auto-discovers tables.

30 minutes
5

Add New Tools

Give the AI new abilities: create charts, export CSV, send emails, search the web. Each tool is one Python function.

1-2 hours each
6

Add RAG (Document Search)

Let the AI search your PDFs, docs, and wiki pages before answering. Uses ChromaDB (local, free) + an embedding model via Ollama.

Half day
7

Fine-Tune a Model (Actual Training)

Use Unsloth + LoRA to train the model on your own Q&A data. Teach it your database schema, your SQL patterns, your jargon. Export to Ollama.

1-2 days
8

Multi-Agent Production System

Multiple AI agents working together: SQL agent, chart agent, report agent. Add authentication, logging, and deploy for a team.

Weeks
